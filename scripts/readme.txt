Внимание: запускать через браузер (/scripts/optimize-uploads.php) или CLI (php scripts/optimize-uploads.php). Требует авторизации в админке, если через браузер.

Резюме изменений
upload.php:

Возвращает URL .webp (если создался).

Создает WebP из оригинала.

Уменьшает JPG/PNG до 1200px (для og:image и старых браузеров), качество 75.

Если GD нет — работает как раньше.

page.php:

Ветка type=page для og:image проверяет наличие .webp файла на диске. Если есть — отдает WebP.

scripts/optimize-uploads.php:

Прогоняет старые файлы, создает .webp и сжимает JPG до 1200px.

Не удаляет JPG, а делает их «легкими».

Пишет лог в data/optimize.log.

Важно: для запуска скрипта создайте папку scripts/ в корне (если её нет) и положите туда файл optimize-uploads.php. Запускать лучше через браузер (ваш-сайт/scripts/optimize-uploads.php), будучи залогиненным в админке. Он пройдет по всем старым картинкам и облегчит их. Уже созданные WebP он пропустит (не будет трогать).
