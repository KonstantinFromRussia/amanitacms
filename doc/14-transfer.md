# 14. Перенос проекта в новый чат

**Проект:** Muhomor.spb.ru (AmanitaLove.ru) · **Версия CMS:** 2.5 · **Актуально на:** 24 октября 2026

---

## 1. Обзор

Этот файл описывает, **как перенести контекст проекта в новый чат** (например, Deepseek, ChatGPT, Claude) без потери информации.

**Проблема:** чаты имеют лимит токенов. Когда лимит близок — нужно начать новый чат, но сохранить контекст.

**Решение:** использовать **бандл** (`bundle/project_bundle.txt`) + **промт-шаблон** (раздел 3).

---

## 2. Что передавать в новый чат

### 2.1. Минимальный набор

- **`bundle/project_bundle.txt`** (~413 КБ) — все значимые файлы в одном тексте.
- **Этот файл** (`14-transfer.md`) — инструкция по переносу.
- **`01-architecture.md`** — общее состояние проекта.
- **`11-roadmap.md`** — что сделано, что в работе, что дальше.

### 2.2. Полный набор (рекомендуется)

- **`bundle/project_bundle.txt`** — код.
- **Все файлы `doc/`** — полная документация.
- **`README.md`** — краткое описание.
- **`13-rules.md`** — правила работы (обязательно!).

### 2.3. Что НЕ передавать

- **Пароли** (`admin_password_hash`, SMTP-пароль) — секреты.
- **Изображения** (`/uploads/*`) — большой объём.
- **Шрифты** (`/fonts/*`) — большой объём.
- **Библиотеки** (`/js/jquery`, `/js/summernote`) — не нужны для контекста.
- **`tailwind-output.css`** — генерируется, большой.

## 4. Что делать после отправки промта

1. **Дождитесь ответа** — новый чат должен подтвердить, что понял контекст и правила.
2. **Проверьте**, что он **не предлагает** удалить комментарии, заменить JSON на MySQL, инлайнить `tailwind-output.css` и т.п.
3. **Задайте задачу** — пошагово, как в правиле 4.
4. **Следите за соблюдением правил** — если новый чат их нарушает, напомните.

## 5. Как собрать бандл (если его нет)

**Файл:** `script2/bundle_project.py`
**Запуск:**

    python bundle_project.py

**Результат:** `bundle/project_bundle.txt` (~413 КБ).

**Что включает:**
- Все `.php` в корне и `/includes/`.
- Все `.json` в `/data/` (кроме секретов).
- `.htaccess` (корень, `/uploads/`, `/includes/`).
- `robots.php`, `sitemap.php`, `llms.txt`.
- `.well-known/ai-catalog.json`, `.well-known/ard.json`.
- `README.md`.
- Скрипты (`customize_cms.py`, `config.yaml`, `bundle_project.py`).

**Что чистит:**
- `admin_password_hash` — удаляется.
- `admin_login` — удаляется.
- Пароль SMTP — **проверьте**, что `mail-config.php` в исключениях (или пароль замаскирован).

**Подробнее** — см. `12-customization.md`.

## 6. Альтернатива — передача файлов по одному

Если бандл слишком большой (или нужно передать только часть):

1. Передайте **`README.md`** (краткое описание).
2. Передайте **`01-architecture.md`** (общее состояние).
3. Передайте **`13-rules.md`** (правила).
4. Передайте **конкретные файлы**, которые нужны для задачи (например, `admin.php`, `admin.js`).
5. Передайте **`11-roadmap.md`** (что дальше).

**Минус:** новый чат не увидит весь код, только то, что передали.
**Плюс:** меньше токенов.

- [ ] Задача сформулирована пошагово
- [ ] Новый чат соблюдает правила (следить)

## 8. Частые ошибки при переносе

| Ошибка | Последствие | Как избежать |
|--------|-------------|--------------|
| Передать бандл **с** `admin_password_hash` | Утечка хеша | Проверить бандл перед отправкой |
| Не передать `13-rules.md` | Новый чат удаляет комментарии | Всегда передавать правила |
| Передать **весь** код (включая `tailwind-output.css`) | Лимит токенов | Использовать бандл |
| Не сформулировать задачу | Новый чат «плывёт» | Вписать задачу в промт |
| Не проверить ответ | Новый чат ломает архитектуру | Проверять первые ответы |
