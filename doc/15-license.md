## 4. Данные пользователей

### 4.1. Какие данные собираются

- **Заказы:** имя, телефон, email, адрес доставки, комментарий, состав заказа.
- **Отзывы:** имя, текст отзыва (email — опционально).
- **Счётчик:** cookie `visitor_id` (анонимный идентификатор), IP-адрес (для фильтрации ботов).
- **Аналитика:** GA4 (анонимные данные о визитах).

### 4.2. Где хранятся

- **Заказы:** `data/orders.json`.
- **Отзывы:** `data/reviews.json`.
- **Счётчик:** `data/counter.json`, `data/counter.log`.
- **Аналитика:** на серверах Google (GA4).

### 4.3. Кто имеет доступ

- **Владелец магазина** (через админку).
- **Хостинг** (технически, через файловую систему).
- **Google** (GA4 — анонимные данные).

### 4.4. Защита данных

- `/data/` защищён `.htaccess` (403).
- `mail-config.php` защищён `.htaccess`.
- Пароль админа — bcrypt-хеш.
- Бэкапы — ZIP, хранятся у владельца.

### 4.5. Что НЕ делается

- **Нет** передачи данных третьим лицам (кроме GA4 — анонимно).
- **Нет** продажи данных.
- **Нет** массовых рассылок без согласия.

## 5. Возрастное ограничение 18+

Проект продаёт **сушёные мухоморы** — продукт, который может быть опасен при неправильном употреблении.

**Что сделано:**
- Окно 18+ при входе на сайт.
- Подтверждение возраста через `localStorage`.
- Юридический компромисс: LCP ~2 сек (окно перекрывает контент).

**Рекомендация:** проконсультируйтесь с юристом по поводу:
- Обязательности окна 18+ (в РФ — для некоторых товаров).
- Дисклеймеров на страницах товаров («не является лекарством», «проконсультируйтесь с врачом»).
- Условий доставки и возврата.

## 7. Бэкапы и восстановление

### 7.1. Кто отвечает

- **Владелец** — за регулярность бэкапов.
- **Хостинг** — за сохранность сервера (но **не** за данные сайта).

### 7.2. Что делать при потере данных

1. **Проверить бэкапы** (ZIP-архивы).
2. **Восстановить** из последнего бэкапа.
3. **Проверить** сайт и админку.
4. **Сделать новый бэкап**.

### 7.3. Рекомендации

- **Бэкап раз в неделю** (минимум).
- **Перед крупными изменениями** — обязательно.
- **Хранить в двух местах** (локально + облако).
- **Проверять бэкапы** (открывается ли ZIP, целы ли файлы).

**Подробнее** — см. `02-install.md`, п. 7.
