# 09. Оптимизация PageSpeed

**Проект:** Muhomor.spb.ru (AmanitaLove.ru) · **Версия CMS:** 2.5 · **Актуально на:** 24 октября 2026

---

## 1. Обзор

Оптимизация PageSpeed в проекте велась по трём направлениям:

- **Изображения** — WebP, `fetchpriority`, `width`/`height`, сжатие логотипа.
- **CSS** — инлайн `themes.css`, удаление Font Awesome, отказ от `all.min.css`.
- **Шрифты** — локальный Roboto (без Google Fonts), preload (опционально).

**Цель:** снизить время блокировки CSS и улучшить LCP/CLS.

---

## 2. Что сделано

| Что | Экономия |
|-----|----------|
| WebP для всех изображений | −32% размера |
| `themes.css` инлайн (в `head.php`) | −450 мс блокировки |
| `all.min.css` удалён (Font Awesome) | −750 мс, −25 КБ |

## 3. Детали по каждому пункту

### 3.1. WebP для всех изображений

- Автоматическая конвертация при загрузке (`upload.php`).
- `<picture>` с WebP + fallback на оригинал (`renderPicture()` / `buildPicture()`).
- Старые картинки сконвертированы через `batch-webp.php`.
- **Подробнее** — см. `07-images.md`.

**Экономия:** −32% размера изображений.

### 3.2. `themes.css` инлайн

- Файл `css/themes.css` **инлайнится** в `includes/head.php` (в `<style>`).
- **Зачем:** убирает блокирующий CSS-запрос (≈450 мс).
- **Минус:** HTML становится чуть больше, но это компенсируется скоростью.

**Экономия:** −450 мс блокировки.

### 3.3. `all.min.css` удалён (Font Awesome)

- Ранее использовался **Font Awesome** (`all.min.css`).
- Заменён на **inline-SVG** (`includes/icons.php` + `getMaxIcon()` и др.).
- **Зачем:** Font Awesome — это ~25 КБ + блокирующий CSS-запрос (≈750 мс).

**Экономия:** −750 мс, −25 КБ.

### 3.4. Font Awesome → inline-SVG

- Все иконки (соцсети, интерфейс) — в `includes/icons.php`.
- Вывод через функции (`getMaxIcon()`, `socialUrl()` и др.).
- **Плюс:** нет внешнего CSS, иконки рендерятся сразу, легко стилизовать через CSS.

**Экономия:** −25 КБ (нет шрифта Font Awesome).

### 3.5. Логотип: `fetchpriority` + `width`/`height`

- В `<img>` логотипа:
  - `fetchpriority="high"` — приоритет загрузки (LCP).
  - `width`/`height` — фиксированные размеры (CLS = 0).
- **Зачем:** логотип — это LCP-элемент на главной. Без `fetchpriority` он грузится позже, LCP растёт. Без `width`/`height` — CLS (сдвиг вёрстки).

**Экономия:** LCP ↓, CLS = 0.

### 3.6. Логотип сжат (50 КБ → 16 КБ)

- Исходный логотип был ~50 КБ.
- Сжат до ~16 КБ (без потери качества).
- **Экономия:** −34 КБ.

### 3.7. Шрифты preload (опционально)

- `<link rel="preload" as="font" type="font/woff2" href="/fonts/roboto-regular.woff2" crossorigin>`.
- **Зачем:** убирает FOUT (мерцание шрифта).
- **Опционально:** можно не использовать, если шрифты грузятся быстро.

**Экономия:** −150 мс.

## 4. Что осталось (низкий приоритет)

### 4.1. LCP ~2 сек

**Причина:** окно 18+ (возрастная проверка) — юридический компромисс. Окно перекрывает контент, LCP-элемент не виден до подтверждения.

**Решение:** оставить как есть (юридический компромисс). Либо: сделать окно 18+ менее навязчивым (не перекрывать контент, а показывать баннером сверху) — но это меняет UX, требует согласования с владельцем.

### 4.2. `tailwind-output.css` — внешний

- `tailwind-output.css` **оставлен внешним** файлом.
- **Причина:** инлайн ломал вёрстку на Windows-хостинге (баги с кодировкой/переносами).
- **Минус:** блокирующий CSS-запрос (~200–300 мс).
- **Решение:** оставить как есть (стабильность важнее).

### 4.3. Пересборка Tailwind (иконки)

- **Проблема:** после кастомизации (`customize_cms.py`) слетели цвета иконок — Tailwind не сгенерировал arbitrary values (`text-[var(--accent)]`, `bg-[var(--bg-card)]`).
- **Результат:** иконки белые.
- **Решение:** пересобрать `tailwind-output.css` с учётом всех arbitrary values.
- **Статус:** отложено (низкий приоритет, пока игнорируем).
- **Подробнее** — см. `11-roadmap.md` (средний приоритет).

## 6. Рекомендации по дальнейшей оптимизации

- **Критический CSS** — вынести критический CSS в `<style>` в `head.php`, остальной — отложенно. (Риск: ломка вёрстки на Windows-хостинге, как с `tailwind-output.css`.)
- **Ленивая загрузка iframe** — если есть iframe (карты, видео), добавить `loading="lazy"`.
- **Preconnect** — для внешних доменов (GA4, если используется).
- **Сжатие HTML** — минификация HTML (осторожно с Windows-хостингом).
- **HTTP/2** — проверить, включён ли на хостинге (LiteSpeed обычно поддерживает).

**Но:** не всё стоит делать. **Стабильность важнее** — на Windows-хостинге многие «улучшения» ломают вёрстку.
