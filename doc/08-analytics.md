## 2. Google Analytics 4 (GA4)

### 2.1. ID

**GA4 ID (пример):** `G-XXXXXXXXXX`

**Где хранится:** в `data/settings.json` (поле `ga4_id` или аналогичное — вписывается через админку).

### 2.2. Подключение

- В админке → «⚙️ Настройки» → поле «GA4 ID» → вписать ваш ID.
- Код GA4 выводится в `includes/head.php` (или `footer.php` — по реализации).
- **Статус:** подключён и работает (если ID вписан).

### 2.3. Проверка

1. Откройте сайт в браузере.
2. Откройте `https://analytics.google.com` → выберите ресурс.
3. «Отчёты» → «В реальном времени» — должны появиться визиты.
4. Если визитов нет — проверьте:
   - GA4 ID в админке.
   - Код GA4 в исходном коде страницы (`Ctrl+U` → поиск вашего ID).
   - Блокировщики рекламы (могут блокировать GA4).

## 3. Google Tag Manager (GTM)

### 3.1. Статус

**GTM не грузится напрямую.** Причина — ошибка `ERR_NAME_NOT_RESOLVED` для `fonts.googleapis.com` (и, возможно, для других доменов Google).

### 3.2. Обход

**Решение:** добавление IP в файл `hosts` на **локальной машине** (не на сервере).

**Шаги (Windows):**
1. Откройте `C:\Windows\System32\drivers\etc\hosts` (от имени администратора).
2. Добавьте строку:

       142.250.74.163 fonts.googleapis.com

3. Сохраните.
4. Сбросьте DNS-кеш: `ipconfig /flushdns` (в командной строке от администратора).
5. Перезагрузите браузер.

**Результат:** GTM (и Google Fonts, если используются) начнут грузиться на вашей машине.

> ⚠️ **Обход только для локальной машины.** На сервере и у посетителей GTM может не грузиться (проблема DNS на стороне хостинга/провайдера).

### 3.3. Нужен ли GTM?

**Вопрос открытый.** GA4 подключён напрямую (без GTM). Если GTM не нужен для дополнительных тегов (пиксели, события, A/B-тесты) — можно **не подключать**. Если нужен — решать проблему с DNS на уровне хостинга (обращение в поддержку).

## 4. Яндекс.Метрика

### 4.1. Статус

**Подключена.** ID вставлен через админку, код Метрики выводится, визиты видны в «Realtime» (`https://metrika.yandex.ru`). **22.11.2026**

### 4.2. Что сделано

- В админке → «⚙️ Настройки» → поле «Яндекс.Метрика ID» — заполнено.
- Код Метрики выводится в `includes/head.php` (или `footer.php` — по реализации).

### 4.3. Проверка

1. Откройте сайт в браузере.
2. Откройте `https://metrika.yandex.ru` → выберите счётчик.
3. Раздел «В реальном времени» — должны появиться визиты.
4. Если визитов нет — проверьте код Метрики в исходном коде страницы (`Ctrl+U` → поиск `ym(` или `metrika`).

## 5. Счётчик посетителей (внутренний)

**Файл:** `includes/counter.php`.

- Считает уникальных посетителей (cookie `visitor_id` на 1 год).
- Фильтры: админы, боты, API/AJAX, не-GET.
- Хранение: `data/counter.json`.
- Вывод: в футере через `getVisitorCount()`.

**Зачем:** быстрый взгляд на трафик без внешних инструментов, независимость от GA4/Метрики. Подробнее — см. `01-architecture.md`, п. 5.10.

## 6. Что можно улучшить (Roadmap)

- **GTM** — решить проблему с DNS или отказаться (низкий приоритет).
- **Цели в GA4** — настроить конверсии (оформление заказа, отправка отзыва, клик по телефону).
- **События GA4** — кастомные события (добавление в корзину, начало оформления).
- **Дашборд** — сводка по трафику и заказам в админке (низкий приоритет, см. `11-roadmap.md`).
