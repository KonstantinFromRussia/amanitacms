## 1. Обзор

Тестирование проекта включает:

- **Функциональное** — публичная часть, админка.

- **Сборка документации** — `build_docs.py`.
- **Произвольные страницы** — вкладка «📄 Страницы», `/<slug>`, меню, sitemap, Schema.org `WebPage`. **04.11.2026**

## 7. Тестирование индикаторов событий

**Что проверить:**

1. **Бейдж на вкладке «⭐ Отзывы»:**
   - Отправьте **тестовый отзыв** через форму на странице товара.
   - Откройте админку → вкладку «⭐ Отзывы».
   - **Ожидается:** красный бейдж с числом «1» на вкладке, отзыв **сверху** списка, **красная полоса** слева, бейдж «🆕 Новый».

2. **Бейдж на вкладке «📦 Заказы»:**
   - Оформите **тестовый заказ** через корзину.
   - Откройте админку → вкладку «📦 Заказы».
   - **Ожидается:** красный бейдж «1», заказ **сверху**, **красная полоса**, бейдж «🆕 Новый».

3. **Общий счётчик в заголовке:**
   - Если есть **новый отзыв + новый заказ** — «⚙️ Админ-панель сайта **(2 новых)**».

4. **Favicon:**
   - Сверните браузер — на **иконке вкладки** видна **цифра**.
   - После обработки всех событий — **исчезает**.

5. **Авто-проверка:**
   - Оставьте админку открытой.
   - Отправьте **новый отзыв** через форму в другом браузере.
   - Подождите **60 секунд**.
   - **Ожидается:** всплывающее уведомление «🆕 Новый отзыв на модерации!», бейдж обновился.

6. **Публикация отзыва:**
   - Нажмите **«✅ Опубликовать»** рядом с новым отзывом.
   - **Ожидается:** бейдж исчез, отзыв опубликован, зелёная подсветка убрана.

7. **Смена статуса заказа:**
   - Откройте заказ, смените статус с «Новый» на «В обработке».
   - **Ожидается:** бейдж на вкладке «📦 Заказы» уменьшился/исчез, favicon обновился.

## 8. Тестирование фичи «Страницы» (04.11.2026)

**Сценарий 1 — создание опубликованной страницы**

1. Админка → вкладка «📄 Страницы».
2. Заполнить: `title = "Доставка"`, `slug = "delivery"`, `content = "<p>Тест</p>"`, `status = on`, `show_in_menu = on`, `sort_order = 20`.
3. «💾 Сохранить».
4. **Ожидается:**
   - страница в списке, статус «опубликована · в меню · sort: 20»;
   - `/delivery` открывается, `<h1>Доставка</h1>`, контент, хлебные крошки «Главная / Доставка»;
   - в шапке (десктоп + мобильное) появился пункт «Доставка» после «Отзывы»;
   - в `sitemap.xml` есть `<loc>.../delivery</loc>`, `changefreq=monthly`, `priority=0.6`;
   - Schema.org `WebPage` + `BreadcrumbList` (проверить в Rich Results Test).

**Сценарий 2 — черновик**

1. Создать страницу `title = "Политика"`, `slug = "policy"`, `status = off`.
2. «💾 Сохранить».
3. **Ожидается:**
   - `/policy` → 404 (дружелюбная `404.php`);
   - в меню нет;
   - в `sitemap.xml` нет.

**Сценарий 3 — редактирование slug**

1. Открыть страницу `delivery`, изменить `slug` на `dostavka`.
2. «💾 Сохранить».
3. **Ожидается:**
   - `/delivery` → 404;
   - `/dostavka` открывается;
   - в меню пункт ведёт на `/dostavka`;
   - в `sitemap.xml` старый `loc` исчез, новый появился.

**Сценарий 4 — конфликт slug**

1. Создать страницу `title = "Доставка 2"`, `slug = "delivery"` (уже занят).
2. «💾 Сохранить».
3. **Ожидается:** ошибка «Slug „delivery“ уже занят», страница не сохраняется.

**Сценарий 5 — невалидный slug**

1. Создать страницу `slug = "Доставка"` (кириллица).
2. «💾 Сохранить».
3. **Ожидается:** ошибка «Slug: только латиница, цифры и дефис».

**Сценарий 6 — удаление**

1. Открыть `dostavka`, нажать «🗑».
2. Подтвердить.
3. **Ожидается:**
   - `/dostavka` → 404;
   - пункт исчез из меню;
   - `loc` исчез из `sitemap.xml`.

**Сценарий 7 — изображение**

1. Открыть страницу, загрузить `image` (jpg/png).
2. **Ожидается:**
   - URL в поле, превью под полем;

**Сценарий 8 — меню и сортировка**
