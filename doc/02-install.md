# 02. Установка и первоначальная настройка

**Проект:** AmanitaCMS · **Версия CMS:** 2.5 · **Актуально на:** 22 ноября 2026

**Демонстрационные сайты:** `muhomor.spb.ru`, `amanitalove.ru`

---

## 1. Требования к хостингу

| Компонент | Требование |
|-----------|-----------|
| PHP | 7.1+ (рекомендуется 7.4+) |
| Веб-сервер | Apache или LiteSpeed с `mod_rewrite`, `mod_headers`, `mod_deflate`, `mod_expires` |
| GD (php-gd) с WebP | Для авто-конвертации изображений |
| ZipArchive | Для резервного копирования |
| Права на запись | `/data/` и `/uploads/` |
| SMTP | Для отправки почты (порт 587, STARTTLS) |

**Текущий хостинг:** DirectAdmin, Windows, PHP 7.1, LiteSpeed, гипервизор `ha005`.

> ⚠️ На Windows-хостинге `rename()` не атомарен — поэтому счётчик защищён через `flock()` (см. `01-architecture.md`, п. 5.10).

---

## 2. Быстрая установка

1. **Скопируйте файлы** в корень сайта (FTP/файловый менеджер хостинга).
2. **Проверьте `.htaccess`** в корне сайта.
3. **Проверьте `/uploads/.htaccess`** — запрет исполнения PHP.
4. **Проверьте `/includes/.htaccess`** — защита includes.
5. **Установите права:** `chmod -R 755 data uploads`.
6. **Откройте сайт** в браузере — должна загрузиться главная.

## 3. Первоначальная настройка

### 3.1. Первый вход

1. Откройте `https://ваш-сайт/admin.php`.
2. **Логин:** `admin`, **Пароль:** `secret123`.

> ⚠️ Дефолтный пароль **активен только до первой смены**. Смените сразу!

### 3.2. Смена пароля

1. Админка → «⚙️ Настройки» → «🔐 Смена пароля».
2. Старый пароль (`secret123`), новый — дважды.
3. Сохранить.

> ⚠️ **Пароль нельзя восстановить** (bcrypt-хеш). Сохраните в менеджере паролей. Если забыли — см. `03-admin.md`.

### 3.3. Настройки сайта

В «⚙️ Настройки» заполните:

| Поле | Что вписать |
|------|-------------|
| `site_name` | Короткое название (например, «Мой сайт») |
| `site_seo_title` | Длинный title для `<title>` |
| Контакты | Телефон, email, адрес |
| Соцсети | TG, VK, YouTube, MAX |
| Логотип / Favicon | Загрузить через админку |
| GA4 ID | `G-XXXXXXXXXX` (ваш идентификатор) |
| Яндекс.Метрика ID | Ваш ID счётчика (проверить визиты в «Realtime») |

### 3.4. Настройка почты

1. Откройте `includes/mail-config.php` (FTP/файловый менеджер).
2. Заполните SMTP-параметры:

       'host'       => 'mail.example.com',
       'port'       => 587,
       'encryption' => 'tls',           // STARTTLS
       'username'   => 'noreply@example.com',
       'password'   => 'ВАШ_ПАРОЛЬ',
       'from_email' => 'noreply@example.com',
       'from_name'  => 'AmanitaCMS',
       'admin_email'=> 'admin@example.com',

3. Сохраните.
4. Проверьте: оформите тестовый заказ → письмо на `admin_email`.
5. Шаблоны писем — `includes/email-templates.php`.

> ⚠️ **Пароли в `mail-config.php`** — не выкладывайте в публичный доступ, не коммитьте в GitHub.

### 3.5. Первый бэкап

1. Админка → «⚙️ Настройки» → «📦 Резервное копирование».
2. «📦 Скачать резервную копию».
3. Скачается ZIP `<домен>-backup-YYYY-MM-DD-HHMMSS.zip`.
4. **Сохраните в двух местах:** локально + в облаке. Не храните только на сервере.

## 5. Работа с изображениями

Кратко: при загрузке через `upload.php` — проверка MIME + `getimagesize()`, транслит кириллицы, проверка дубликатов. **11.11.2026:** WebP создаётся из уменьшенной копии (макс. 1200px, качество 82), JPG-оригинал сжимается (качество 75, макс. 1200px) и остаётся fallback. Если GD/WebP недоступны — сайт работает на оригиналах.

- **Старые картинки:** `rename-all-images.php` (SEO-имена), `scripts/optimize-uploads.php` (WebP + сжатие JPG). Запускать **один раз**, после — удалить скрипты с сервера.
- **Подробно — см. `07-images.md`.**

## 6. Перенос на другой домен

1. Скопируйте все файлы на новый хостинг.
2. Скопируйте `/data/` и `/uploads/` (с содержимым).
3. Проверьте `.htaccess` в корне, `/uploads/.htaccess`, `/includes/.htaccess`.
4. `SITE_URL` определится автоматически (протокол + `HTTP_HOST`).
5. Админка → «⚙️ Настройки» → сохранить (обновит `robots.txt`).
6. **Почта:** `includes/mail-config.php` — SMTP-хост может отличаться. Обновите.
7. **Sitemap:** `/sitemap.xml` должен отдаваться корректно.
8. **404:** несуществующий URL → 404 (не 200).
9. **Редиректы:** HTTP → HTTPS, WWW → без WWW (301).
10. **Бэкап** на новом месте.

---

## 7. Обновление файлов (FTP)

> ⚠️ При обновлении через FTP **переподключайтесь** — клиент может не видеть новые файлы.

**Порядок:**
1. Скачайте бэкап через `backup.php`.
2. Загрузите новые файлы.
3. **Не перезаписывайте** `data/settings.json` (там `admin_password_hash` и настройки).
4. **Не перезаписывайте** `includes/mail-config.php` (SMTP-пароли).
5. **Не удаляйте** `tailwind-output.css` (внешний файл, инлайн ломал вёрстку).
6. Проверьте сайт и админку.

## 8. Типичные проблемы при установке

| Проблема | Причина | Решение |
|----------|---------|---------|
| Белый экран | Ошибка PHP | Включить `display_errors` в `php.ini` / лог хостинга |
| 500 Internal Server Error | Ошибка в `.htaccess` | Проверить синтаксис, закомментировать подозрительные строки |
| `sitemap.xml` не открывается | `MultiViews` в Apache | `Options -MultiViews` в `.htaccess` |
| Картинки не конвертируются в WebP | Нет GD/WebP | Установить `php-gd` с WebP |
| Письма не приходят | SMTP-настройки | Проверить `includes/mail-config.php`, логи хостинга |
| Письма в спаме | Проблема получателя | Сменить получателя (например, на Яндекс) |
| Счётчик сбрасывается | Race condition | Проверить `counter.log`, убедиться, что `flock()` работает |
| Пароль забыт | bcrypt-хеш | См. `03-admin.md` |

## 10. Документация (сборка HTML)

Для лендинга `amanitacms.ru` MD-документация конвертируется в HTML скриптом `build_docs.py`.

**Требования:** Python 3.7+, `pip install markdown`.
**Запуск:** `python build_docs.py` из корня проекта.

**Результат:** `doc/*.html`, `doc/index.html`, `doc/assets/docs.css` (создаётся один раз, потом можно править).

**Обновление:** после правки MD — перезапустить скрипт. HTML перезапишется, CSS останется.
