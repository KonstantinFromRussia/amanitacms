# 07. Изображения и WebP

**Проект:** AmanitaCMS · **Версия CMS:** 2.5 · **Актуально на:** 3 ноября 2026

**Демонстрационные сайты:** `muhomor.spb.ru`, `amanitalove.ru`

---

## 1. Обзор

Работа с изображениями в проекте построена на **автоматической WebP-конвертации** и **SEO-именах файлов**. Цель — уменьшить вес страниц (PageSpeed) и улучшить индексацию картинок в поиске.

**Что сделано:**
- WebP-конвертация при загрузке (`upload.php`).
- Транслитерация кириллицы в SEO-имена.
- Проверка на дубликаты.
- `<picture>` с WebP + fallback на оригинал (`renderPicture()` в PHP, `buildPicture()` в JS).
- SEO-переименование старых картинок (`rename-all-images.php`).
- Batch-WebP-конвертация старых картинок (`batch-webp.php`).

## 2. Загрузка изображений (`upload.php`)

### 2.1. Валидация

При загрузке через админку:
- **`finfo`** — проверка MIME-типа.
- **`getimagesize()`** — проверка, что это реально изображение (а не переименованный PHP-скрипт).
- **Двойная валидация** — оба метода должны подтвердить.

### 2.2. Транслитерация имени

- Кириллица в имени файла транслитерируется в латиницу.
- Пробелы → дефисы.
- Спецсимволы удаляются.
- **Пример:** `Мухомор красный 100г.jpg` → `muhomor-krasnyy-100g.jpg`.

### 2.3. Проверка на дубликаты

- Если файл с таким именем уже есть — добавляется суффикс (`-1`, `-2`, ...).
- Либо используется уникальное имя `img_<timestamp>_<random>.<ext>` (по реализации).

### 2.4. WebP-конвертация

- Если GD с WebP доступен — создаётся `.webp`-копия (качество 82).
- **Если WebP больше оригинала** — WebP-копия удаляется (нет смысла).
- Если GD/WebP недоступны — сайт работает на оригиналах (функциональность не страдает).

### 2.5. Результат загрузки

- Оригинал (`.jpg`/`.png`) — сохраняется.
- WebP-копия (`.webp`) — если конвертация успешна.
- Имя — SEO-транслит (или `img_<timestamp>_<random>`, по реализации). <!-- БЫЛО: Имя — SEO-транслит. -->

## 3. Вывод изображений

### 3.1. PHP — `renderPicture()`

**Файл:** `includes/helpers.php`

**Что делает:**
- Формирует `<picture>` с двумя `<source>`:
  - `<source type="image/webp" srcset="...webp">`.
  - `<img src="...jpg" ...>` (fallback для старых браузеров).
- Добавляет `width`/`height` (для CLS = 0).
- Добавляет `loading="lazy"` (кроме логотипа).
- Логотип — `fetchpriority="high"` (LCP).

**Пример использования:**

    <?= renderPicture('/uploads/example.jpg', 'Описание', 400, 400) ?>

**Результат:**

    <picture>
      <source type="image/webp" srcset="/uploads/example.webp">
      <img src="/uploads/example.jpg" alt="Описание" width="400" height="400" loading="lazy">
    </picture>

### 3.2. JS — `buildPicture()`

**Файл:** `js/script.js`

**Что делает:** аналог `renderPicture()` для динамической подгрузки (корзина, каталог через fetch).

**Использование:** при рендере товаров/статей из JSON в браузере.

### 3.3. Fallback

- Браузеры без WebP (старые Safari, IE) — получают оригинал (`.jpg`/`.png`).
- Браузеры с WebP — получают `.webp` (меньше вес).

### 3.4. OG и Schema.org

- **OG-теги** (`og:image`) и **Schema.org** (`Product.image`) — остаются на **JPEG** (не WebP).
- Причина: не все соцсети и AI-агенты корректно обрабатывают WebP.

## 4. SEO-переименование старых картинок (`rename-all-images.php`)

**Назначение:** одноразовый скрипт для переименования старых картинок в SEO-имена.

**Когда запускать:** после внедрения транслитерации в `upload.php`, если в `/uploads/` остались файлы с «мусорными» именами (`IMG_1234.jpg`, `photo.png`, кириллица).

**Что делает:**
- Читает `/uploads/`.
- Транслитерирует имена.
- Переименовывает файлы (и `.webp`-копии, если есть).
- Обновляет ссылки в `data/*.json` (товары, блог, новости, акции).

**Запуск:** `https://ваш-сайт/rename-all-images.php` (одноразово).

> ⚠️ **После запуска — удалить скрипт с сервера.** Иначе любой сможет его запустить.

**Результат (по факту):** старые картинки переименованы в SEO-имена, ссылки в JSON обновлены.

---

## 5. Batch-WebP-конвертация (`batch-webp.php`)

**Назначение:** одноразовый скрипт для конвертации старых картинок в WebP.

**Когда запускать:** после внедрения WebP в `upload.php`, если в `/uploads/` остались `.jpg`/`.png` без `.webp`-копий.

**Что делает:**
- Читает `/uploads/`.
- Для каждого `.jpg`/`.png` — создаёт `.webp` (качество 82).
- Если WebP больше оригинала — удаляет WebP.

**Запуск:** `https://ваш-сайт/batch-webp.php` (одноразово).

> ⚠️ **После запуска — удалить скрипт с сервера.**

**Результат (по факту):** все старые картинки получили `.webp`-копии.

## 6. Оптимизация PageSpeed (изображения)

| Что | Экономия |
|-----|----------|
| WebP для всех изображений | −32% размера |
| Логотип: `fetchpriority="high"` + `width`/`height` | LCP ↓, CLS = 0 |
| Логотип сжат (50 КБ → 16 КБ) | −34 КБ |
| `<picture>` с WebP + fallback | Совместимость + скорость |

**Результат:** CSS-блокировка снизилась с 1960 мс до ~600 мс (частично за счёт WebP).

**Осталось (низкий приоритет):**
- LCP ~2 сек — из-за окна 18+ (юридический компромисс).
