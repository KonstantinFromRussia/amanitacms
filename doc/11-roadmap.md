### 4.2. Этап 1 — Базовые улучшения (быстро, 1–2 часа)

#### 4.2.1. Фильтр по статусу

**UI:** кнопки над списком заказов.

    [ Все (15) ] [ 🆕 Новые (3) ] [ ⏳ В обработке (5) ] [ 📦 Отправленные (4) ] [ ✅ Выполненные (3) ]

**Действие:** клик → показываются только заказы с выбранным статусом.
**Плюс:** счётчики рядом с каждой кнопкой — сразу видно, сколько заказов в каком статусе.

#### 4.2.2. Цветовая индикация

**В шапке заказа** — цветной кружок:
- **🆕 Новый** — красный.
- **⏳ В обработке** — жёлтый.
- **📦 Отправлен** — синий.
- **✅ Выполнен** — зелёный.

**В выпадающем списке** — тоже цветной фон.

#### 4.2.3. Сортировка

**UI:** выпадающий список над заказами.
- **Новые сверху** (по умолчанию).
- **Старые сверху.**
- **По сумме (дорогие).**
- **По сумме (дешёвые).**

#### 4.2.4. Поиск

**UI:** поле ввода над списком.
**Ищет по:** имя, телефон, email, ID заказа, название товара.

### 4.3. Этап 2 — Автоматизация (2–4 часа)

#### 4.3.1. Уведомления клиенту

**При смене статуса** — **автоматическое письмо**:

| Из | В | Тема письма |
|-----|---|-------------|
| — | Новый | «Заказ #N принят» |
| Новый | В обработке | «Заказ #N собирается» |
| В обработке | Отправлен | «Заказ #N отправлен, трек-номер: ...» |
| Отправлен | Выполнен | «Заказ #N доставлен. Спасибо!» |

**Настройка:** шаблоны писем в админке.
**Технология:** SMTP (уже настроен).

#### 4.3.2. Автоматические напоминания админу

- Если заказ **«Новый»** больше **24 часов** — напоминание.
- Если заказ **«Отправлен»** больше **5 дней** — напоминание позвонить клиенту.

### 4.4. Этап 3 — Аналитика (4–8 часов)

#### 4.4.1. Дашборд заказов

**На вкладке «📦 Заказы»:**
- **Всего заказов** за месяц.
- **Средний чек.**
- **Конверсия** (заказы / посещения).
- **График** по дням / неделям / месяцам.

#### 4.4.2. Экспорт в CSV / Excel

- Кнопка «📊 Экспорт».
- Скачивание файла с **всеми заказами** за период.
- Формат: UTF-8 с BOM (для Excel).

#### 4.4.3. Статистика по товарам

- **Топ-10 товаров** по продажам.
- **Топ-10 по выручке.**
- **Не продающиеся товары** (для акции).

### 4.7. Что делать первым

**Рекомендую начать с трёх задач — они дадут максимальный эффект за минимальное время:**

1. **Фильтр по статусу** — 30 минут.
2. **Цветовая индикация** — 20 минут.
3. **Уведомления клиенту** — 2 часа (SMTP уже работает).

**После них** админка заказов станет **полноценным инструментом работы**, а клиенты будут **в курсе** каждого этапа.

### 4.8. Что НЕ нужно делать

**Проверено опытом — не стоит тратить время:**

- **Сложная CRM** — для магазина с 10–50 заказами в день **избыточно**.
- **Много интеграций** — начните с **одной** (например, СДЭК).
- **Кастомный редактор заказов** — админки **достаточно**.
- **Сложные отчёты** — Excel/CSV **достаточно**.

**Фокус:** **простота** и **скорость работы**, а не **богатство функций**.
